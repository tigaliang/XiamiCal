# 虾米日历 XiamiCal

在 Mac 菜单栏，随手查农历、放假和补班。免费、无需登录，离线可用。

**[从 Mac App Store 下载](https://apps.apple.com/app/id1633055190)** · [反馈问题](https://github.com/tigaliang/XiamiCal/issues)

适用于 macOS 12.3 及以上，支持 Apple 芯片和 Intel Mac。

![虾米日历：公历农历与假期安排](docs/images/calendar-overview.png)

## 用它做什么

- 点开菜单栏图标，查看公历、农历和当月日历。
- 看清中国大陆放假与补班日期，“休”“班”分别标记。
- 选中一天，查看农历、传统节日、生肖与日期详情。
- 按月或按年翻阅，一键回到今天，支持键盘导航。
- 支持浅色、深色、VoiceOver 和系统减少动态效果/降低透明度设置。

## 安装后怎么打开

1. 在 Mac App Store 下载并打开虾米日历。
2. 应用出现在屏幕顶部的菜单栏，不显示 Dock 图标。第一次打开会展开日历。
3. 点击菜单栏图标可再次展开；点击面板外收起。

找不到图标时，可以从“应用程序”或 Spotlight 再次打开虾米日历；菜单栏空间不足时，先收起其他应用的菜单栏项目。

## 1.7 新增功能

1.7 的安装可用性以 App Store 显示的版本为准。

- 在日历右下角“…”→“设置…”中，可选择菜单栏显示“15 周二”这样的紧凑日期，或只显示图标。
- macOS 13 及以上支持“登录 Mac 时启动”开关，启用后登录时静默出现在菜单栏。若系统要求允许登录项，可从设置中的按钮继续操作。
- macOS 12.3–12.x：在“系统偏好设置 → 用户与群组 → 登录项”点击“+”添加应用。
- 点击日历中的“数据说明”，查看当前年份覆盖范围和官方通知来源。
- “…”菜单提供使用帮助、问题反馈和复制下载链接。

## 日期数据范围

公历固定节日和农历传统节日按日期计算；闰月不会重复标记传统节日。**节日名称不代表当天一定放假。** 清明是节气，当前内置 2022–2026 年的核验日期。

中国大陆放假调休安排已收录 **2022–2026 年**，来源为国务院办公厅年度通知，通过应用更新补充。1.7 对未收录年份明确提示“调休安排未收录”，不会把缺少数据的日期判断成工作日或放假日。周末颜色仅区分星期，实际工作安排以所在单位通知为准。

如果发现日期问题，请在 [Issues](https://github.com/tigaliang/XiamiCal/issues) 中提供具体公历日期、预期结果、应用版本及 macOS 版本；GitHub 提交问题需要账号。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 回到今天 | ⌘T |
| 上/下个月 | ⌘← / ⌘→ |
| 上/下一年 | ⌥⌘← / ⌥⌘→ |
| 选择相邻日期 | 点击日期后使用方向键 |
| 关闭日历 | Esc |
| 设置（1.7） | ⌘, |

## 隐私

应用无需登录，不收集使用数据，日历查询离线可用。打开帮助、官方数据来源或 App Store 链接时，由浏览器或 App Store 访问对应网站。

[隐私政策](https://github.com/tigaliang/XiamiCal/wiki/XiamiCal-Privacy-Policy)
